# Coffe_Shop_Sales

☕ Coffee Shop Sales Analysis Dashboard (Excel)

📌 Project Overview --

This project presents an interactive Coffee Shop Sales Analysis Dashboard built entirely in Microsoft Excel using Power Query, Pivot Tables, Power Pivot, and Data Visualization techniques. The dashboard analyzes transactional sales data to uncover customer purchasing behavior, sales trends, product performance, and store-wise insights, enabling data-driven business decisions.

🎯 Objectives --
Analyze overall sales performance and key business KPIs.
Identify top-selling products and categories.
Evaluate sales trends by month, weekday, and hour.
Compare store-wise revenue and customer footfall.
Build an interactive dashboard using Excel slicers and Pivot Charts.
